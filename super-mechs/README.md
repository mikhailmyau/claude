# 🤖 SUPER MECHS — браузерный ремейк

Полностью рабочий клон **Super Mechs** (Tacticsoft / Gato Games) на чистом
HTML/CSS/JavaScript — без сборки и зависимостей. Открой `index.html` в браузере
и играй. Прогресс сохраняется в `localStorage`.

## Как запустить
```
Просто открой super-mechs/index.html в любом современном браузере
(или задеплой папку на GitHub Pages / любой статический хостинг).
```

## Реализовано по ТЗ

### Мастерская (Workshop)
- Точный набор слотов: **1 Torso, 1 Legs, 2 Top Weapon, 4 Side Weapon, 1 Drone,
  1 Teleporter, 1 Charge, 1 Hook, 8 Modules** — итого 20 слотов.
- **Лимит веса 1000 кг**; перегруз до 1010 кг со штрафом **−15 HP за 1 кг**;
  свыше 1010 кг мех непригоден к бою (как в оригинале).
- 3 меха в гараже, покраска (10 цветов), живое векторное превью меха из частей.

### Боевая система
- Пошаговый бой 1v1 на **линейном поле из 10 тайлов**, **2 действия за ход**.
- Действия: движение (Walk/Jump, прыжок через врага), выстрел (каждое оружие
  1 раз за ход), **Stomp**, **Teleport** (в любую клетку, урон при приземлении
  вплотную), **Charge Engine** (рывок + урон + push), **Grappling Hook**
  (притягивание + урон). **Дрон** стреляет автоматически каждый ход.
- Три элемента: **Physical / Heat(Explosive) / Energy(Electric)**.
- Ресурсы: энергия (Regeneration каждый ход) и тепло (Cooling каждый ход).
- **Overheat/Shutdown**: превышение теплоёмкости → пропуск хода на вентиляцию,
  при слабом охлаждении — shutdown-loop.
- **Energy Break**: дренаж сверх текущей энергии врага конвертируется в урон.
- Резисты вычитанием (урон − резист), дебаффы (−MaxEng, −MaxHeat, −Reg,
  −Cooling, −Res), **Push / Pull / Recoil**, ограниченные Uses,
  стоимость выстрела (energy/heat), Backfire.
- ИИ противника: оценивает урон/дренаж/нагрев, добивает, избегает перегрева,
  выбивает из дальности (range bullying), использует спец-предметы.

### Предметы и прогрессия
- **60+ предметов** со статами maxed Mythical из ТЗ (Zarkares, Windigo,
  Nightfall, Annihilation, Malice Beam, EMP, Heat Bomb, Corrupt Light,
  Platinum Plating, Quad Core Booster и т.д.).
- Редкости: **Common → Rare → Epic → Legendary → Mythical → Divine**
  с капами уровней **10/20/30/40/50** и цветами из оригинала.
- Премиум-предметы **L-M** (только из премиум-ящиков), **M-only** торс
  Sabretooth.
- **Boost/Fuse**: прокачка «едой» и Power Kits (Common 1200 / Rare 6000 power),
  бонус +10% за совпадение типа, +20% за тип+элемент, золото за фьюз.
- **Transform** по формулам ТЗ: C→R 2 предмета+25к, R→E 3+25к, E→L 4+50к,
  L→M 5+100к, M→D через **Ascension Relics** (2-5 по базовому тиру + 100к-1млн).

### Режимы
- **Кампания**: 2 главы × 8 миссий × 3 сложности (Normal/Hard/Insane),
  враги Buggy/Tank/Mech, чёрные боссы, +5 токенов за первое прохождение,
  реликвии за Insane-боссов.
- **Арена**: ранги **25 → 1** (3/4/5 звёзд за ранг), противники скейлятся по
  рангу, **Arena Coins за первые 5 побед в день**, магазин арены
  (6 перманентных бустов по 10 уровней), награды за ранг, реликвии на топ-рангах.
- **Рейд**: 6 тиров, награда зависит от сохранённого HP.
- **Ежедневные задания** (+10 токенов) и достижения-статистика.

### Экономика
- Валюты: **Gold, Tokens, Arena Coins, Ascension Relics**.
- Ящики: Mix / Silver (2 предмета) / **Premium Box / Premium Pack**
  (гарантированный Epic+, эксклюзивные L-M).
- Уровень игрока до 250, токены за левел-апы, XP за бои.

### Осознанные отличия от оригинала
- Только 1v1 (2v2/3v3, кланы, титаны — вне MVP по этапам ТЗ).
- Система «топлива» убрана намеренно (рекомендация ТЗ).
- Названия предметов сохранены для узнаваемости, арт полностью оригинальный
  (векторная отрисовка на canvas, без ассетов оригинала).

## Структура
```
super-mechs/
├── index.html      — оболочка
├── css/style.css   — стили (тёмная тема)
└── js/
    ├── data.js     — база предметов, тиры, формулы, кампания, ящики
    ├── core.js     — состояние, инвентарь, статы меха, экономика, сейвы
    ├── battle.js   — боевой движок + ИИ
    ├── render.js   — векторные мехи, сцена боя, частицы, звук (WebAudio)
    ├── ui.js       — все экраны и модалки
    └── main.js     — точка входа
```

Логика покрыта headless-тестами (Node) — 400 автобоёв ИИ-vs-ИИ без ошибок,
UI проверен Playwright-сценарием (полный бой до победы реальными кликами).
